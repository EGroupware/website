EGroupware Version 20.1 ist bald verfügbar

In der Presse · 10.08.2020

EGroupware erhält eine Erweiterung für videobasiertes Lernen und Lehren, für Video­konferenzen und für die Fernnutzung von Firmen-⁠PCs. Darüber hinaus machen zwei technische Neuerungen die Collaboration-Software ressourcenschonend und sicher.

Die neue EGroupware Version 20.1 wird am 12. August 2020 erscheinen.

EGroupware erhält eine Erweiterung für videobasiertes Lernen und Lehren, für Video­konferenzen und für die Fernnutzung von Firmen-⁠PCs. Darüber hinaus machen zwei technische Neuerungen die Collaboration-Software ressourcenschonend und sicher.

Kaiserslautern, 10.08.2020 - Ein neues Modul für EGroupware ist"smallPART". Das Akronym steht für "selfdirected media assisted learning lectures & Process Analysis Reflection Tool". Mit smallPart und EGroupware können Lehrer Kurse erstellen, Videos - auch mit Anmerkungen an bestimmten Stellen - einfügen und Aufgaben beschreiben. Andererseits können die Lernenden diese Videos jederzeit kommen­tieren oder Fragen hinzu­fügen. Diese Anmerkungen können von den Lehrern und, wenn genehmigt, auch von anderen Schülern gesehen werden.
Externe Teilnehmer erhalten eine E-⁠Mail mit einem Link zur Teilnahme an der Konferenz. Die Daten­verbindung ist verschlüsselt, und solange der Server in Deutsch­land steht, gibt es keine datenschutz­rechtlichen Bedenken. Es wird kein weiteres Werkzeug benötigt. Jitsi läuft in einem Webbrowser.

Das Tool smallPART ist das Ergebnis einer Kooperation von Arbeits­gruppen der Universität Tübingen und der Technischen Universität Kaiserslautern. Die Weiter­entwicklung und Integration in EGroupware ist eine Kooperation zwischen der TU Kaiserslautern, namentlich Prof. Dr. Christoph Thyssen und Arash Tolou, und EGroupware. Das Modul smallPART ist unter der GNU Affero General Public License 3.0 und damit in allen Varianten von EGroupware kostenlos verfügbar.
Aufgrund der Corona-Krise und der notwendigen Umstellung auf das Arbeiten aus dem Home-Office hat das Kaiserslauterer Software­haus ursprünglich für die Version 20.1 geplante Funktionen vorgezogen und die Version 19.1 im April 2020 veröffentlicht. Jetzt sind die Integration von Videokonferenz­systemen auf Basis von "Jitsi" und ein weiteres nachrüstbares Modul "Guacamole" verfügbar.
Zum einen ist es möglich, die Open-Source-Anwendung Jitsi in EGroupware zu integrieren. Diese kombiniert die Funktionen der Videokonferenz­lösung (Video, Audio, Chat, Desktop-Sharing) mit den Business-Funktionen von EGroupware wie geplante Video­konferenzen, Einladen von Teilnehmern per E-⁠Mail oder Ad-⁠hoc-⁠Anrufe. Zum anderen trägt das Guacamole-Modul der absehbar verstärkten Nutzung von Home Office Rechnung: Es ermöglicht die Nutzung leistungshungriger Anwendungen auf Firmen-Desktops und -Servern aus dem Webbrowser privater Anwender-⁠PCs, ohne dass eine zusätzliche Lizenz erforderlich ist. Der Zugriff erfolgt über VNC/RDP/SSH und ist mit SSL-⁠Verschlüsselung, 2-Faktor-Authentifizierung, Rechte­verwaltung und Brute-Force-Schutz gesichert. Die Daten bleiben, wo sie hingehören: im Unter­nehmen!
Die Version 20.1 von EGroupware bringt eine technische Neuerung, die künftig sukzessive in alle Module der Kollaborations­software eingeführt wird: den auf PHP Swoole basierenden Push-Server, eine NodeJS-ähnliche Technologie für PHP-⁠Umgebungen.
Damit ist sicher­gestellt, dass die Kunden über sie betreffende Neuigkeiten unverzüglich informiert werden. Mit der Integration von PHP Swoole in EGroupware 20.1 wird die Kalender­ansicht inklusive Timesheet und Infolog aktualisiert, sobald jemand eine Änderung vornimmt, eine Termin­anfrage sendet oder einen Termin eingibt.

Nutzt ein Kunde den E-⁠Mail-Dienst von EGroupware oder hat sein eigenes Dovecot entsprechend konfiguriert, erhält er dank dieser Push-Technologie ohne Verzögerung eine übersichtliche Anzeige der neu eingegangenen Mails mit Absender, Empfänger­konto und Betreff­zeile.
Die EGroupware GmbH wird diese Technik für zukünftige Versionen erweitern und für möglichst viele weitere Mail­server verfügbar machen.
Die Anwender werden jedoch nichts Neues in EGroupware bemerken: Die Entwickler stellen den Client- und Browser-seitigen Code von JavaScript auf TypeScript um. TypeScript bietet nach Meinung vieler Programmierer die beste Lösung für komplexere Anwendungen eine bessere Entwicklungs­umgebung, macht sie produktiver und reduziert Fehler­quellen.
