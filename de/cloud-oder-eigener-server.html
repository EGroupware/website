Cloud oder eigener Server?

EGroupware gibt es als Cloud-Dienst aus Deutsch­land und zur Installation auf Ihrem eigenen Server – mit derselben Software. Diese Seite hilft bei der Entscheidung. Und wenn sich Ihre Anforderungen ändern, wechseln Sie einfach: in beide Richtungen.

Zum Vergleich Beratung anfragen
Im Überblick

Die beiden Betriebs­modelle im Vergleich

Gleiche Software, gleiche Daten – der Unterschied liegt darin, wer den Server betreibt und wie viel Sie selbst in der Hand haben möchten.

Entscheidungs­hilfe

Was passt zu Ihrem Team?

Die meisten Organisationen finden sich in einer der beiden Spalten deutlich wieder.

Die Cloud passt, wenn …

  • Sie keine eigene IT haben oder diese entlasten möchten.
  • Sie schnell starten möchten – ohne Server und Installation.
  • Updates und Daten­sicherung zuverlässig erledigt sein sollen.
  • Sie feste monatliche Kosten statt eigener Hardware bevorzugen.

Der eigene Server passt, wenn …

  • Sie den Server voll­ständig selbst in der Hand haben möchten – vom Betriebs­system bis zum Zeitpunkt der Updates.
  • Sie eigene Anpassungen oder Module direkt im Quellcode umsetzen möchten.
  • Die Daten Ihr Haus aus rechtlichen oder internen Gründen nicht verlassen dürfen.
  • Sie IT-⁠Know-⁠how im Haus haben oder einen Dienstleister beauftragen.
Der Mittelweg

Eigener Server, betreut vom EGroupware-Team

Die Daten müssen im Haus bleiben, aber Ihnen fehlt die Zeit für die Administration? Dann installiert und wartet das EGroupware-Team die Software auf Ihrem Server per Fernwartung – abgerechnet über Support-Kontingente.

Viele Kunden kombinieren den eigenen Server mit einem Support-Kontingent: Den Alltag erledigen sie selbst, für komplexere Fragen haben sie das Team an der Seite, das die Software entwickelt.

Wechseln, wenn sich Anforderungen ändern

Cloud und eigener Server nutzen dieselbe Software. Ein Umzug ist jederzeit möglich, in die eine wie in die andere Richtung – wir unterstützen bei der Migration von E-⁠Mail, Kalender, Kontakten und Dateien.

Auch zwischen Community Edition und Enterprise Line wechseln Sie ohne Daten­migration: Beide nutzen dieselbe Datenbank.

Zum Profil

Häufige Fragen zum Betriebs­modell

Kann ich später zwischen Cloud und eigenem Server wechseln?

Ja, in beide Richtungen. Es ist dieselbe Software; wir unterstützen beim Umzug von E-⁠Mail, Kalender, Kontakten und Dateien. Die Stadt­verwaltung Nordenham hat EGroupware zum Beispiel zwölf Jahre selbst betrieben und ist 2018 in die Cloud gewechselt.

Kann ich die Cloud an mein Active Directory und meinen Datei­server anbinden?

Ja. Active Directory oder LDAP bleiben in Ihrem Haus und werden über eine VPN-⁠Verbindung zwischen Ihrem Netz und unserem Rechen­zentrum angebunden – Benutzer und Passwörter pflegen Sie wie gewohnt an einer Stelle. Auf Wunsch binden wir zusätzlich einen lokalen Datei­server per SMB-⁠Protokoll an, sodass Ihre Ablage im Haus direkt in EGroupware verfügbar ist.

Was ist günstiger – Cloud oder eigener Server?

Die Cloud kostet ab 24,90 € pro Monat oder wird als Flatrate abgerechnet und enthält Betrieb, Updates und Daten­sicherung. Die Community Edition ist ohne Lizenz­kosten, die Enterprise Line gibt es ab 62,50 € pro Monat oder als Flatrate (EPL Universal) – beim eigenen Server kommen Hardware oder Hosting sowie die Arbeits­zeit für Wartung und Sicherung hinzu. Ohne eigene IT ist die Cloud deshalb häufig die günstigere Lösung.

Brauche ich für den eigenen Server eine IT-⁠Abteilung?

Sie brauchen Linux-Kenntnisse für Installation, Updates und Daten­sicherung – im Haus oder über einen Dienstleister. Alternativ übernimmt das EGroupware-Team die Wartung per Fernzugriff auf Basis von Support-Kontingenten.

Wie sicher sind meine Daten in der Cloud?

Die Daten liegen in zwei Rechenzentren in Frankfurt am Main. Der Zugang ist immer verschlüsselt (HTTPS), zusätzlich ist eine Anmeldung mit zwei Faktoren möglich. Wir sichern die Daten täglich und halten 7 tägliche und 12 wöchentliche Sicherungen vor.
