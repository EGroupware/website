# website
EGroupware marketing website (www.egroupware.org)

## Über dieses Repository

Statische Webseite von EGroupware: reines HTML und CSS, ohne Build-Schritt,
ohne Frameworks. Die Dateien werden so veröffentlicht, wie sie im Repository liegen.

- `de/` – deutsche Seiten
- `en/` – englische Seiten (inhaltlich gleich wie `de/`)
- `assets/` – Stylesheet, Skripte und Bilder

## Branches

| Branch    | Wird veröffentlicht auf |
|-----------|-------------------------|
| `staging` | Staging-Seite (Arbeitszweig) |
| `main`    | Live-Seite egroupware.org |

## Regeln für Änderungen

Die Regeln für Aufbau, Texte, Design und Veröffentlichung stehen in
[`.claude/CLAUDE.md`](.claude/CLAUDE.md).
