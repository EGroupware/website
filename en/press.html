Short description

Free to use in your coverage.

Integrative, flexible and secure: online collaboration software made in Germany

Group calendars, address books, tasks and projects, tracking system, file management, email client: EGroupware is open source enterprise software for business use. It supports integrated project teams across and within organisational boundaries. Windows, Linux or Mac – EGroupware runs in the browser and is therefore independent of the operating system. The mobile version provides online access to all data on the go, without any need for synchronisation.

As an open source solution from Germany, EGroupware strengthens its users' digital sovereignty: the source code is open and auditable, data is stored either in two data centres in Frankfurt am Main or on the customer's own server. Open standards and REST APIs enable integration into existing IT landscapes and the freedom to switch at any time.

Linking data across applications and mapping business processes through configurable custom fields make EGroupware the choice for organisations that expect the highest flexibility from collaboration software. Further information: www.egroupware.org
