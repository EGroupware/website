NEWSince EGroupware 26

EGroupware tailored to your organisation

Adapt the colours of the applications and the login page to your corporate identity or back­ground image. You also choose between the rounder "Glossy" design and the classic design and set the font size.

Guide: customising EGroupware 26 (GitHub wiki)

App chooser

All applications in one click

The central app chooser takes you straight to every application – compact as icons or with labels. Change the order of the applications simply by dragging, so the most important ones are always first.

EGroupware 26

The most important new features

Fresh, responsive design

Lists, views and dialogs adapt to the screen size. Clear headers in every application, filters in a drop-down menu and a reduced side menu give you a better overview.

Much better accessibility

Navigation, lists and the login page have been redesigned for screen readers and keyboard use. Dialogs open either in the main window or, as before, in a separate window.

AI tools and intelligent search

AI tools in all text fields and the email editor, plus a search across all applications that combines full-text and semantic search – only if you switch it on.

Rolling releases

Instead of one big version a year, improvements and new features arrive continuously, with new version numbers such as 26.10. You use new features as soon as they are ready.

Documentation

Where do I find documentation on …?

Release notes, guides and technical documentation for users, administrators and developers.

Customising

Custom translations, custom fields and customised dialogs (eTemplates) – update-safe, too.

REST API

Connect and automate contacts, calendars, tasks, email, time­sheets, helpdesk and invoices via the REST API. With OpenAPI descriptions, for example for AI agents and automation tools.

Installation and update

Install or update EGroupware 26 on your own server – via package or Docker.
