Installation

Three ways to the Community Edition

Linux packages with Docker

Recommended for Linux administrators: the packages for Debian, Ubuntu and other distributions set up EGroupware with all containers. Updates run through the package manager.

For everyone who prefers a graphical interface: EGroupware from the Univention App Center, with user management and mail server – managed through the UCS web interface.

Frequently asked questions about the download

What do I need for the installation?

A Linux server with root access and basic Linux administration skills. The packages set up Docker and all required containers. Supported distributions and versions are listed in the installation guide.

How do I keep EGroupware up to date?

With the packages via the package manager of your distribution, on UCS via the Univention App Center. We announce new versions and security updates in the forum.

Community Edition or Enterprise Line?

The Community Edition is open source and comes without licence fees; operation and updates are up to you. The Enterprise Line adds extra features, quality-assured updates and help with the installation.

Is it possible without my own server?

Yes. In the EGroupware Cloud, we run EGroupware for you in a German data centre – including updates and backups. Try the cloud free for 30 days.
