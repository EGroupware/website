Advantages of synchronisation

During synchronisation, the data from the calendar, contacts or tasks are copied and transferred to the corresponding target device. This copy is then constantly synchronised with the organal and changes are synchronised accordingly.

Online access for smart­phones or tablets

In addition to synchronisation, there is also the option of using the mobile template for smart­phones or tablets to access EGroupware data directly in real time. The handling is adapted to mobile devices and you have more possibilities than with pure synchronisation. A set-⁠up for mobile access is not necessary.

mobile template

Which methods are supported

EGroupware offers various protocols for synchronisation. Depending on the device and client, you can use the synchronisation that suits you best. For the calendar we recommend CalDAV and for addresses the CardDAV protocol. The most common smart­phones and desktop clients support this protocol. In addition, synchronisation is possible via eSync, which is based on the Activesync protocol. Case study: Managed Davx5 use in Jena

CalDAVCardDAVCase study: Managed Davx5 use in Jena

DAVx5 for Android

Android does not natively support synchronisation via CalDAV / CardDAV, therefore an additional client is needed. Here we recommend DAVx5 from bitfire web engineering GmbH. For larger organisations, there is also a Managed DAVx5 Version with which smart­phone policies can also be implemented. Bitfire or we would be happy to provide a quote for this. A free version of DAVx5 can be downloaded from F-⁠Droid.

Connecting Desktop Clients to EGroupware

Via CalDAV / CardDAV all common desktop clients such as Thunderbird, EM-⁠Client or MAC Clients can be synchronised with EGroupware. As a rule, you only need your EGroupware login address, your user name and the password. In the EGroupware settings you determine which data should be synchronised.

Outlook Synchronize

With the CalDAV synchroniser, you can synchronise data from the address book and calendar between EGroupware and common Outlook versions. Supported Outlook versions are 2019, 2016 and 2013. The CalDAV Synchroniser makes it easier for EGroupware users to exchange data with Outlook and manage their information.

CalDAV synchroniser

Online File-Server

Your entire team can easily access the EGroupware file manager via a browser - you always see the same, current documents and folders. Alternatively, you can connect your Windows, Mac or Linux desktop as an EGroupware drive via WebDAV - as simply and securely as if you were accessing your hard drive.
