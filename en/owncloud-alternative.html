Owncloud Alternative

Collaboration software has become an indispensable part of modern project work, as it not only enables the central management of files, addresses and appointments, but also supports teams in completing their tasks efficiently and on time. Solutions such as Owncloud are considered standard, but providers are increasingly establishing themselves that are a real alternative to Owncloud thanks to innovative features and moderate pricing.

EGroupware, an alternative to Owncloud

EGroupware is a popular and mature alternative to Owncloud, which not only promotes smooth teamwork, but also ensures cross-project work within companies or research and educational institutions. Owncloud alternative makes work easier for users In addition to the central administration of addresses and appointments, the software also includes modules for project management, task management and time recording. All modules can be activated or deactivated individually according to the customer's needs. The central, configurable dashboard then visualises the available features in a way that suits the individual user. This means that every user has an overview of his or her pending tasks, required contacts and appointments right on the start page, which reduces the risk of missing important deadlines or wasting time unnecessarily looking for required contacts. The central file management system also provides the user with all the resources needed to complete tasks, up to date and easy to find. The hosting of the data can either take place centrally on your own servers or be outsourced to the EGroupware Cloud. Outsourcing the hosting brings with it the usual advantages of reliability and freedom from maintenance. In addition, no further servers have to be purchased, which has a positive effect on the costs.

Development and main features of the Owncloud alternative

EGroupware has its roots in the OpenSource area and is still licensed under GPL. The software is available in the basic version (Community Edition, CE) without licence fees for private users and companies alike. In addition, EGroupware provides a number of paid versions that offer additional functionalities, extended service offerings, hosting and much more. In contrast to some other providers, EGroupware can be accessed via browser, regardless of platform - whether Windows, Mac or from Linux. It is therefore a real Owncloud alternative. The number of database connections is also broad - you can use MySQL, MariDB or PostgreSQL. Especially in the area of interfaces, EGroupware tries to support as many standards as possible and not to force the customer to use proprietary solutions. For example, Active Directory Server (ADS) or LDAP can be used for authentication. Due to the fact that the individual modules can be integrated or deactivated customer-specifically, it is easy for customers to configure a customised solution. If required, EGroupware offers a wide range of workshops and support solutions here for the start and to support the customer with the introduction of EGroupware.

EGroupware features

Besides the standard features like the calendar function or the address book function, EGroupware offers a number of modules that make it a very good Owncloud alternative.

File manager

The file manager makes it possible to store files centrally and make them available to all authorised users. Here, individual folders or files can be released not only for all, but also for a specific group of users. An alternative to Owncloud can simplify every­thing In the case of specific releases, which can also be protected by means of a password, the following occurs the notification of authorised users about links that are automatically sent via mail. The file manager also allows files to be moved using drag and drop and is a good alternative to well-known hosting services such as Dropbox. It is also possible to integrate existing file servers. Alternatively, the data can be encrypted via PGP, which in turn ensures data security.

Synchronisation

Appointments, as well as files and contacts, are of course synchronised in real time. It does not matter whether the data changes were made from mobile devices or from computers. CalDAV, WebDAV, Active Sync and CardDAV are currently supported as communication protocols for mobile devices.

Mail­server

EGroupware can communicate with all common mail servers such as Courier, Cyrus, Exchange or UW IMAP via IMAP. The most common web clients such as Thunderbird, EM Client or Outlook 2013 / 2016 are also supported.

Workflow Engine

The system has a powerful workflow engine, with the help of which tickets can be easily created and processed. This means that business processes can not only be controlled and processed centrally, but also remain in the focus of project management.

Additional features

The list of additional features is long and depends on the version. In the full version, files and folders can also be shared with users who do not have a user account. The corresponding link is sent via email and can also be secured with a password, which in turn can also have an expiry date. In addition, there are features for project management, data security, various backup functions and a content management module. The system also supports the automatic import and export of data as well as the individual design of forms and templates.

EGroupware solutions as Owncloud alternative

If you do not want to host EGroupware yourself, an EGroupware cloud package can be the right solution. This not only provides the customer with an unlimited number of user accounts, but also a comprehensive support package, which also includes training and consulting. The pricing depends on the number of users logged on to the system at the same time. Costs can be saved through multi-year solutions or the purchase of a flat rate. Price advantages are also offered for educational institutions and associations, which makes EGroupware an alternative to other systems. to Owncloud is also interesting for the non-⁠profit sector. Prices for the purchase of a full version are also based on the number of users and again include a comprehensive support package, with training, customisation and data migration, as well as personal contact and technical assistance. Further­more, EGroupware offers an interesting upgrade offer, so that a change from the Community Edition to the full version is easily possible. All versions can be tested in advance free of charge for a limited period of time.

Conclusion on the alternative for Owncloud

EGroupware is a mature and excellently customisable Owncloud alternative, which stands out due to its stability and Flexibility distinguishes. With its ease of use and mobile interface, it also enables all users to work effectively, regardless of time and place.
