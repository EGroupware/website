Enterprise Line

What the Enterprise Line includes

The Enterprise Line (EPL) is the full version for companies and public administrations – with quality-assured packages and the manufacturer at your side.

All features

In addition to the Community Edition: Kanban, print templates and e-⁠invoicing (XRechnung, ZUGFeRD).

Permissions and audit trail

Fine-grained permissions, address book policies for the GDPR and the reason and requester for every administrative change.

Protection for files

Versioning, roll-back and deletion protection – accidentally changed or deleted files can be recovered.

Quality-assured updates

Tested enterprise packages for predictable updates. The licence is valid indefinitely for the version purchased.

Help with installation

Installation support within one month of purchase and application support via the MyEGroupware support platform.

Lower support rates

Support at €175 per hour instead of €350 for the Community Edition – billed from contingents in 15-minute units.

Community Edition and EPL in detail

Integration

Part of your infrastructure

On your own server you use what is already there – or have what you need installed alongside.

User management

Connection to Active Directory, LDAP and single sign-⁠on – EGroupware is also available as an app in the Univention App Center.

Mail and file server

Connect an existing mail server and file server (Samba) – or install EGroupware Mail alongside: the mail server is then managed in EGroupware.

Full control

You decide on the operating system, the data location and the timing of updates – and can implement your own changes in the source code.

Assistance

You run it, we help

You decide how much you take on yourself. The EGroupware team helps with installation and setup, trains administrators and users and, on request, takes care of maintenance via remote access – billed through support contingents.

Support contingents

Recovery plan including restartBACKUP

With your own server, backups are your responsibility: snapshots of the virtual machine, an off-⁠site copy and the EGroupware backup to an external S3 directory. If the server fails, EGroupware can be started again from this S3 storage in our cloud.

Frequently asked questions about your own server

What does my server need?

A Linux server or virtual machine. EGroupware is available as packages for common Linux distributions and as an app in the Univention App Center; installation notes and technical requirements are on the download page.

Can I switch from the Community Edition to the Enterprise Line?

Yes, at any time. Both use the same database – switching requires no migration; emails, contacts and files stay where they are.

Which contract term applies to self-hosted installations?

The minimum term is one year. The EPL licence is valid indefinitely for the version purchased.

Can I move to the cloud later?

Yes. Cloud and own server use the same software; we help you move email, calendars, contacts and files – and back again.
