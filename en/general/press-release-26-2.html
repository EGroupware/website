Press release - EGroupware 26.2

General · February 9, 2026

New release model, modern & fully responsive frontend, improved accessibility and UI customization, introduction of AI integration

Press Release

EGroupware 26.2 Released

  • New release model
  • Modern, fully responsive frontend
  • Improved accessibility and UI customization
  • Introduction of AI integration

Kaiserslautern, February 9, 2026—EGroupware GmbH announces the release of version 26.2 of its open-source collaboration platform with integrated online office capabilities. The update introduces a new release model, a modern, fully responsive frontend, and enhanced accessibility and UI customization, establishing a solid foundation for the platform's ongoing evolution.

A New, More Transparent Release Model

With version 26.2, EGroupware continues the structural evolution of the platform, moving well beyond a conventional feature update. Rather than focusing on isolated enhancements, the release introduces foundational changes that define the direction of future development.

At the core is a new release model based on a clear year-⁠and-⁠month scheme. EGroupware now delivers updates as a rolling release with explicitly named major and maintenance updates. This approach brings greater transparency to release cycles and makes it easier for users, partners, and administrators to anticipate when new functionality will become available and what updates to expect.

A New Frontend Foundation and UX Redesign

With version 26.2, EGroupware transitions its user interface to a new technical foundation. The frontend is built on a modern, component-based web framework and fully implemented as a responsive interface. This ensures a consistent user experience across devices while establishing a solid base for the platform's ongoing development.

The new frontend architecture is accompanied by a refined user experience. A central app chooser, clearly defined app headers, and a reduced sidebar place stronger focus on the active application and improve overall orientation within the interface. The updated look and feel is therefore not merely a visual refresh, but a deliberate long-term decision in both UI and platform architecture.

Accessibility and Central UI Configuration

With the new frontend, EGroupware 26.2 further advances accessibility across the platform. Navigation, list views, and the login page have been refined to better support screen readers and keyboard navigation. Dialogs can optionally be displayed within the main application window to improve orientation and accessibility; traditional browser pop-⁠ups remain available as an alternative.

At the same time, the interface gains additional flexibility. Administrators can centrally control the order and presentation of applications, define colors for the login page and app headers, and determine how applications appear in the app chooser. This allows EGroupware to be tailored to organizational requirements, day-⁠to-⁠day workflows, and corporate design guide­lines—without requiring additional code-level customization.

AI Integration with an Open Architecture and Full Control

With version 26.2, EGroupware integrates AI capabilities through three independent applications that can be enabled separately for individual users or groups. The official release includes the RAG application and the AI Tools, while an AI assistant for open-ended prompts is currently in a prototype stage and will be released at a later date.

The RAG application provides an platform-wide search and combines classic full-text search with a semantic search based on Retrieval-Augmented Generation (RAG). Both search methods are indexed separately and can be configured independently or combined as a hybrid search. Semantic search requires access to an embedding model; BGE-⁠M3 is recommended.

In addition, AI Tools are available via an icon in the navigation bar across all relevant text fields and the rich text editor, for example when composing emails or working with Infolog entries. These tools support translation, rephrasing, and tone and wording adjustments, as well as the creation of response drafts. For translations, the DeepL service can also be used as an alternative.

The AI integration follows an open, opt-⁠in approach and is activated only after explicit configuration. EGroupware can be connected either to locally operated AI models or to external services, such as via API keys or cloud-based offerings with a fixed monthly budget. For hosting and EPL customers as well as community users, EGroupware GmbH also provides its own AI service, hosted in Germany by IONOS and DeepL. Alternatively, AI models can be run on local infrastructure, for example using Ollama, or integrated via other providers offering an OpenAI-compatible API.

Further expansion of the AI capabilities is planned over the course of the year, including the integration of files into RAG scenarios and the connection of external workflow tools via MCP.
